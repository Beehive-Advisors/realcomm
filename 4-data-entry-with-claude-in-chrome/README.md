# Exercise 4: Data entry with Claude in Chrome
Here, we're once again turning unstructured data into structured data, but the structured data requires entry into a browser-based user interface. 

Before starting this exercise, make sure you have the Claude in Chrome plugin installed and opened on a Google Chrome tab. 

## Exercise 4.1: inspect the user interface
We've created a simulated PMS interface at [beehive-advisors.com/realcomm](https://beehive-advisors.com/realcomm). Inspect this interface; it allows users to enter in certificate of insurance (COI) information. In addition, inspect the sample COI in this directory. 

Once you've familiarized yourself, return to the Claude interface and ensure Cowork has exercise 4 selected. Then, ask Cowork to populate the information from the COI into the interface at [beehive-advisors.com/realcomm](https://beehive-advisors.com/realcomm) specifically using Claude in Chrome. 

Be specific: we want Claude Cowork to read the COI, and click through the different fields in the form and submit. 

## Exercise 4.2: draft a letter informing the tenant of the missing insurance
Ask Claude to draft a concise document asking Aspen Hollow Ophthalmology to fulfill their auto liability requirement.

## Exercise 4.3: create an agent skill
Let Claude know that you want to create an agent skill out of the conversation history. Also, it's good to prompt Claude to ask any outstanding questions to you, the user. 

Now, we're ready to productionize this workflow in exercise 5.
